🏨 Hotel Review Analysis – Summary
This project focuses on analyzing 5000 customer reviews from three hotels to assess performance on Booking.com. The dataset includes ratings on specific aspects such as Cleanliness, Location, Comfort, Staff, Value for Money, and Free WiFi, along with overall ratings and textual reviews.

🔍 Key Steps:
Data Cleaning & Transformation: Standardized ratings, filled missing values, and labeled sentiment (Positive, Neutral, Negative) based on overall rating.

Exploratory Data Analysis (EDA): Explored review distribution by hotel, average ratings, and correlations between sub-categories.

Sentiment Analysis: Applied machine learning (TF-IDF + Logistic Regression) to predict sentiment from review text, providing insights into customer satisfaction.

Visual Insights: Charts like bar graphs, pie charts, and heatmaps highlighted hotel performance, common strengths, and areas needing improvement.

📌 Key Insights:
Hotel Elegance scored highest on average ratings.

Staff and Location showed strong correlation with overall satisfaction.

Majority of reviews were positive, indicating high customer satisfaction.

Sentiment analysis revealed the tone of reviews often aligned with the numerical ratings.
